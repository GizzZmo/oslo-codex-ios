# Oslo Codex — iOS 27

Native iPhone companion for **Oslo Codex** by [Jon Arve Ovesen](https://open.spotify.com/artist/1lYfFl2Ar26wZtEIfdeFSl).
Nordic rap noir. Cybergroup Incorporated.

This repository currently holds the **product spec and agent prompt**.
The Xcode project is generated from [`AGENTS.md`](AGENTS.md) and [issue #1](https://github.com/GizzZmo/oslo-codex-ios/issues/1).

Not a web wrapper. Not a link farm. A real album companion: listen on official platforms, read lyrics, walk Oslo from the record, share a track, pin a widget.

## Run (once the Xcode project exists)

```text
Open OsloCodex.xcodeproj in Xcode 27+
Select the OsloCodex scheme, iPhone 17 (iOS 27) simulator
Command-R
```

Minimum: **iOS 27**, iPhone only, SwiftUI, Liquid Glass chrome, App Intents.
Bundle ID: `no.cybergroup.oslocodex`

## How to generate the app

1. Open [issue #1](https://github.com/GizzZmo/oslo-codex-ios/issues/1) (Scaffold iOS 27 album companion).
2. Assign **GitHub Copilot coding agent** (or paste `AGENTS.md` into Cursor / Codex).
3. Drop official assets when ready: cover 3000x3000, tracklist + ISRC, lyrics, artist photo, DSP album URLs.
